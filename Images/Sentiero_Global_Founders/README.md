# Images/Sentiero_Global_Founders/

Founder photos live here directly (no extra nested `/images/` folder).

The Founders page currently expects:

```
Aryan_Garg.jpg
Pratyaksh_Sharma.jpg
Founders_1.jpg   Founders_2.jpg   Founders_3.jpg
Founders_4.jpg   Founders_5.jpg   Founders_6.jpg
```

The `Founders_*.jpg` files feed the scrolling gallery at the bottom of the page — add as many or as few as you like; just add or remove the matching `<img>` line in `/Sentiero_Global_Founders/index.html`.

Missing photos show a tasteful placeholder, never a broken image icon.
