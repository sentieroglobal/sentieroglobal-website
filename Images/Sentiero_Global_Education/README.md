# Images/Sentiero_Global_Education/

Images for the Sentiero Global Education pages.

The homepage hero currently expects:

```
Education_Poster.png
```

Add any other Education images here and reference them from the relevant page in `/Sentiero_Global_Education/` as `Images/Sentiero_Global_Education/your-file-name.jpg`.

Missing images never break the layout — a tasteful placeholder shows instead until the real file is added.
