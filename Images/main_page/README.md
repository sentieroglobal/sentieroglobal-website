# Images/main_page/

Images for the root Sentiero Global homepage.

Add a hero image here named:

```
SentieroGlobal_Hero.jpg
```

(`.jpg`, `.png` or `.webp` all work — just keep the name `SentieroGlobal_Hero` and update the extension in `index.html` if it isn't `.jpg`.)

Until a real image is added, the homepage shows a tasteful placeholder instead of a broken image icon — nothing will look broken if you leave this folder empty for now.
